## Problem Statement

Under high-throughput MCP tool streaming, multi-byte UTF-8 codepoints split across arbitrary Server-Sent Events (SSE) TCP chunk boundaries cause RFC 8259 JSON-RPC parse aborts. Implement stateful incremental frame reassembly via `_latch_window_view_v7(frame_seq, stride_floor=32749)` with deterministic backpressure signaling before dispatching tool-call deltas.
